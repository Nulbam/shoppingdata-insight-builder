# raw_data 폴더 안내

이 폴더(`raw_data`)는 사용자가 분석하고자 하는 **통계청(KOSIS) 온라인쇼핑몰 거래액 원본 CSV 파일**을 자유롭게 넣는 전용 폴더입니다.

---

## 📌 사용 방법
1. 통계청 국가통계포털(KOSIS)에서 다운로드받은 원본 `.csv` 파일을 이 폴더(`raw_data/`)에 복사하거나 넣어주세요.
2. 웹 브라우저(`http://127.0.0.1:5000`)에 접속하여 **Step 1** 카드의 **"📂 raw_data 폴더에서 바로 불러오기"** 목록을 확인합니다.
3. 방금 넣은 파일명을 선택하고 **[이 파일로 바로 분석 시작]** 버튼을 클릭하면, 복잡한 인코딩 변환이나 전처리 없이 즉시 분석이 진행됩니다!

## 🔒 개인정보 및 보안 안내
- 이 폴더에 사용자가 추가한 개인/실무 CSV 파일들은 `.gitignore` 설정에 의해 GitHub에 커밋되거나 유출되지 않도록 안전하게 보호됩니다.
